💌 Invitation Website

A modern and elegant invitation website created as a personal web project. The site is designed to present an invitation in a beautiful, responsive, and interactive format.

✨ Features

🎉 Elegant invitation landing page

📱 Fully responsive design for mobile, tablet, and desktop

💜 Modern and attractive UI

🖼️ Support for invitation images and decorative elements

✨ Smooth animations and visual effects

🔗 Easy to deploy with Vercel

⚡ Fast loading and lightweight frontend

🛠️ Technologies Used

HTML5

CSS3

JavaScript

React / Vite (if applicable)

Vercel for deployment

🚀 Getting Started

1. Clone the repository

git clone https://github.com/MrAnkit047/INVITATION.git
cd INVITATION

2. Install dependencies

npm install

3. Start the development server

npm run dev

Open the local URL shown in your terminal, usually:

http://localhost:5173

4. Build for production

npm run build

The production files will normally be generated in:

dist/

5. Preview the production build

npm run preview

🌐 Deployment

This project can be deployed easily using Vercel.

Vercel settings for Vite

Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
Install Command: npm install

After connecting the GitHub repository to Vercel, push changes to the main branch and Vercel can automatically create a new deployment.
